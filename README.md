# ORBIT HOP

A portrait, one-thumb neon arcade game built with Flutter and Flame. Tap to launch your blob toward the next rotating planet, collect coins on the flight, chain perfect landings, and keep ahead of the rising danger zone.

## Run

1. Install the Flutter stable SDK (3.38.1 or newer), Android Studio, Android SDK Platform 36, and a Java 17 JDK.
2. From the repository root, run `flutter pub get` and then `flutter run` on an Android device or emulator.
3. Ads, Google Play Games, Firebase, and purchases are optional. Without account configuration the game still runs offline; store purchases remain safely disabled until the HTTPS verifier is configured.

See [`SETUP.md`](SETUP.md) for Android/Firebase/ads/purchase setup, [`TESTING.md`](TESTING.md) for verification, and [`LAUNCH.md`](LAUNCH.md) for signing and Play release steps. Product and listing guidance is in [`STORE.md`](STORE.md); the privacy notice is [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md).
